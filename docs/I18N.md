# Languages

Estonian and English, everywhere. Estonian is the default because the contact and most of the
course study in Estonian.

## How it works

No i18n library. `messages/et.json` and `messages/en.json` hold every user-facing string, and
`lib/i18n` is about a hundred lines around them: `useT()` returns a `t(key, vars)` that looks a
dot path up in the dictionary for the current language.

A library would have given us plural rules for languages we do not ship and routing we do not
want. Two languages and a cookie need less than that.

```tsx
const t = useT();
t("empty.decks.title"); // "Ühtegi pakki veel ei ole"
t("nav.step", { step: 2 }); // "Samm 2"
t("card.count", { count: 1 }); // "1 kaart"  → picks card.count_one
t("card.count", { count: 7 }); // "7 kaarti" → picks card.count_other
```

Two conventions on top of the lookup:

- `{name}` in a message is replaced from `vars`.
- a numeric `vars.count` prefers `<key>_one` or `<key>_other`, so "1 kaart" and "7 kaarti" stay
  separate strings instead of being glued together in a component.

## Where the choice lives

The switch in the header writes `flashcards_locale`, a year-long cookie. The root layout reads it
on the server, so `<html lang>` and the first paint are already right; `I18nProvider` then holds
it in React state, which is why switching re-renders the strings in place instead of navigating —
a half-written paste or a running practice session survives the switch.

Reading a cookie in the layout opts the app out of static prerendering. That is the price of not
having the page flash Estonian at an English reader.

## Rules

1. No user-facing string in a component. If you are typing a sentence into JSX, it belongs in the
   dictionary — `aria-label`, `title` and placeholder text included.
2. Add the key to both files in the same commit.
3. `t()` keys are typed. `en.json` is typed against `et.json`, so a key Estonian has and English
   does not fails `npm run typecheck`.
4. `npm run check:messages` catches what typing cannot: a key only English has, an empty string,
   and a `{placeholder}` that one language dropped.
5. Do not build a sentence out of two keys. Word order differs between the two languages; use one
   key with a `{placeholder}`.
